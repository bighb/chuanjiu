seasoning:
  timeline:
    - when: 上炉初期
      what: 什么都不加
      body: 先让表皮受热收紧定型，此时撒料容易掉进炭火里烧糊。
    - when: 表皮定型后
      what: 刷一层薄油
      body: 补足油膜，帮助后续干料附着，也让表皮更油亮。
    - when: 转中文火后
      what: 孜然粉 + 辣椒面
      body: 转小火后再撒料，避免高温把料烤糊发苦。
    - when: 起锅之前
      what: 熟芝麻
      body: 收尾增香。

fire:
  body: 先猛火定型锁汁，再转中文火慢慢烤透——带骨带皮的肉块比薄片更需要时间，全程猛火容易外焦里生。
  photoHint: 表皮焦褐、划刀处微微裂开的特写
  stages:
    - name: 猛火锁边
      duration: 2–3 分钟
      body: 高温快速让表皮收紧上色，锁住内部肉汁。
    - name: 中火烤透
      duration: 6–7 分钟
      body: 转中火，勤翻面，让骨头附近的肉也充分受热。
    - name: 文火收尾
      duration: 2 分钟
      body: 转到炉边余火处收干表面，让料吃进油里。
  charcoal: 果木炭为佳，烤制时间较长，稳定持续的炭火更合适。
  doneness: 表皮焦褐有光泽，划刀处能看到肉质变白、不见血水，用竹签扎透骨头附近的肉没有阻力。

localVariants:
  wuhan: 料汁偏辣，起锅前会补刷一层辣椒油。
  anlu: 咸鲜为主，孜然比例更高，辣度相对克制。

pitfalls:
  - title: 腌制时间不够
    body: 带骨带皮的肉块比薄片难入味，腌不够 60 分钟只有表皮有味，咬到骨头边还是寡淡的。
  - title: 全程猛火
    body: 外皮很快烤焦，骨头附近的肉还没熟透，容易夹生。
  - title: 没有表面划刀
    body: 不划刀的话调料很难渗进厚实的肉里，也不容易判断熟度。
