sourcing:
  body: 选**粉藕（淀粉含量高的藕）**而不是脆藕——粉藕烤透后绵软粉糯，脆藕烤再久也是脆的，达不到烤藕该有的口感。选藕身粗壮、孔洞排列规整的。
  photoHint: 一段藕的横切面，露出孔洞与藕肉质地
  checks:
    - title: 看孔洞
      body: 孔洞排列整齐、大小均匀的多半是粉藕。
    - title: 看颜色
      body: 断面乳白无锈斑发黑。
    - title: 摸重量
      body: 同样大小掂着偏沉的水分足，不发糠。

skewering:
  body: 切成 **8–10 毫米厚片**，太薄容易烤干发柴，太厚中心不容易烤透。竹签从藕片侧面穿入，一串 2–3 片即可，片太多受热不均匀。
  diagram: chunk
  diagramNote: 厚切藕片逐片穿入，片间不留缝隙，方便受热均匀。
  photoHint: 穿好的一串平放特写，能看清藕片孔洞

marinating:
  body: 藕片不预腌，直接上炉现刷料，靠中途多次刷油刷酱慢慢渗入孔洞入味。

seasoning:
  timeline:
    - when: 上炉初期
      what: 刷一层薄油
      body: 藕片吸油快，先刷油防止表面烤干开裂。
    - when: 烤至半透
      what: 灌一次料汁（生抽+蚝油+蒜末调的汁）
      body: 趁孔洞受热张开，把料汁灌进孔洞里，这是烤藕入味的关键一步。
    - when: 起锅之前
      what: 辣椒面 + 葱花
      body: 最后撒料收尾，增香提色。

fire:
  body: 中火慢烤，让厚切藕片有足够时间把内部烤透变软糯，猛火只会外焦内生。
  photoHint: 表面微焦、孔洞渗汁的特写
  stages:
    - name: 中火烤透
      duration: 6–8 分钟
      body: 中火慢烤，勤翻面，让藕片均匀受热直至内部软化。
    - name: 收汁上色
      duration: 2 分钟
      body: 灌汁后转到火力稍旺处收干表面汁水，逼出焦香。
  charcoal: 果木炭为佳，慢烤时间长，稳定的炭火更省心。
  doneness: 藕片边缘微焦、竹签能轻松扎透中心，孔洞里的料汁微微冒泡。

localVariants:
  wuhan: 灌汁偏咸鲜，蒜香更重，起锅前额外撒一把葱花提香。
  anlu: 料汁里会加一点甜面酱调和，口味略带回甘。

pitfalls:
  - title: 藕片切太薄
    body: 薄片受热快，还没等灌汁孔洞就已经烤干，吃着发柴。
  - title: 全程猛火
    body: 外皮很快焦黑，内部还是生脆的，达不到软糯口感。
  - title: 忘记灌汁
    body: 少了灌汁这一步，藕片只有表面有味，孔洞里寡淡无味。
