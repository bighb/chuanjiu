sourcing:
  body: 选**细长条形的紫皮茄子**，皮薄肉厚籽少。太粗的茄子籽多肉糙，烤出来发苦发涩。表皮应该光滑有光泽，蒂头新鲜不发蔫。
  photoHint: 两三条茄子并排的特写，露出表皮光泽
  checks:
    - title: 看粗细
      body: 细长条比粗短的籽少肉嫩。
    - title: 看表皮
      body: 光滑有光泽，没有褶皱和斑点。
    - title: 摸蒂头
      body: 蒂头新鲜不发蔫，说明是新摘的。

skewering:
  body: 烤茄子不走穿串这条路——整条纵向对半剖开，切面朝下直接搁在烤网上，靠茄子自身的皮撑住形状，不需要竹签固定。
  diagram: none
  photoHint: 剖开后切面朝下摆在烤网上的特写

marinating:
  body: 不预腌。茄子肉吸汁性强，靠烤软后淋料入味即可，预腌反而容易出水影响口感。

seasoning:
  timeline:
    - when: 上炉初期
      what: 切面刷一层薄油
      body: 防止切面直接接触烤网烤焦发苦，也帮助后续锁住水分。
    - when: 烤至完全软塌
      what: 用刀在茄子肉上划几道
      body: 划开方便料汁渗入，也方便食客直接用勺子挖着吃。
    - when: 划开之后
      what: 淋蒜蓉料汁
      body: 蒜末、生抽、香油调成的料汁均匀淋在划开处，让茄子肉吸饱汁水。

fire:
  body: 文火慢烤是烤茄子的关键——整条茄子体积大，猛火只会外皮烤焦、内部还是生的，得靠文火慢慢把内部烤软烤透。
  photoHint: 划开淋汁后的整体特写
  stages:
    - name: 文火烤透
      duration: 10–12 分钟
      body: 切面朝下，文火慢烤，让茄子肉逐渐软塌出汁。
    - name: 淋汁收尾
      duration: 2–3 分钟
      body: 划开淋汁后再烤片刻，让料汁渗透并微微收干。
  charcoal: 果木炭为佳，慢烤时间长，火力稳定更省心。
  doneness: 用筷子一戳就能轻松扎透，茄子肉完全塌软、颜色转深。

localVariants:
  wuhan: 蒜蓉料汁里额外调一点小米辣圈，咸鲜里带一丝辣。
  anlu: 料汁更清淡，蒜香为主，很少额外加辣。

pitfalls:
  - title: 用猛火图快
    body: 猛火下外皮很快烤焦，里面还是生的，夹生的茄子肉发涩不好吃。
  - title: 提前预腌
    body: 茄子肉吸水性强，提前腌会大量出水，烤出来发柴不绵软。
  - title: 没烤透就划开淋汁
    body: 茄子肉还没软塌就划开，料汁流不进去，全流到烤网上浪费了。
