sourcing:
  body: 选 **上五花（靠近肋排的上层五花）**，肥瘦比例约四比六，层次分明不散。要冷鲜肉不要冻肉——冻肉解冻后水分流失，烤出来发柴；也不要热气肉，排酸不足有腥气。
  photoHint: 整块上五花的横切面，露出肥瘦层次
  checks:
    - title: 看层次
      body: 肥瘦五层以上、纹路清晰，按下去能回弹。
    - title: 看颜色
      body: 瘦肉粉红有光泽、肥肉乳白，发暗发灰的不要。
    - title: 摸表面
      body: 微干或微湿润皆可，发黏出水的坚决不买。

skewering:
  body: 半冻状态下顶刀切 **3 毫米薄片**——太厚逼不出油，太薄一烤就干。竹签波浪式穿入，每片过签两次固定不打转；一串 4–5 片，片与片之间留一指缝隙让热气穿过。
  diagram: wave
  diagramNote: 肉片呈 S 形过签两次，翻面时不打转、受热面最大。片间留缝，热气对流，熟得均匀。
  photoHint: 穿好的一串平放特写，看得清片间缝隙

marinating:
  body: 腌 **30 分钟**足够——五花片薄，久腌出水反而柴。
  basis: 每 500 克
  recipe:
    - name: 盐
      amount: 4 克
      purpose: 底味，宁少勿多，炉边还要补盐
    - name: 白糖
      amount: 3 克
      purpose: 提鲜，高温下参与上色
    - name: 生抽
      amount: 8 毫升
      purpose: 咸鲜与酱香的来源
    - name: 姜蒜水
      amount: 15 毫升
      purpose: 去腥，比直接放姜蒜末更清爽不糊签
    - name: 白胡椒粉
      amount: 1 克
      purpose: 解腻增香
  callout: 为什么不放料酒？明火直烤时间短，酒精还没来得及带走腥味就挥发殆尽，去腥没起到作用，反而可能在高温下留下焦苦味；去腥交给姜蒜水更稳妥。也不放嫩肉粉——薄片五花不需要，口感会假嫩。

seasoning:
  timeline:
    - when: 上炉初期
      what: 什么都不加
      body: 先让肉自己出油。此时撒料只会掉进炭里烧糊，白白起苦烟。
    - when: 出油之后
      what: 刷一层薄油
      body: 菜籽油混少许猪油，补足表面油膜，让后续干料能挂得住。
    - when: 六七成熟
      what: 盐 + 孜然粉
      body: 第一轮干料趁油撒，翻两下让料均匀吃进油里。
    - when: 起锅之前
      what: 辣椒面 + 熟芝麻 + 孜然粒
      body: 辣椒面后放才不糊、香而不苦；武汉打法在这一步再刷两遍蒜蓉甜辣酱。

fire:
  body: 三段式：猛火锁边 → 中火逼油 → 文火上料。
  photoHint: 边缘焦卷、肥肉透明的特写
  stages:
    - name: 猛火锁边
      duration: 1–2 分钟
      body: 贴近炭面高频翻面，把表面快速烤定型，锁住肉汁。听声辨火：密集的滋滋声。
    - name: 中火逼油
      duration: 3–4 分钟
      body: 抬高一档，慢慢把肥肉里的油逼出来。油滴落炭上起烟，烟熏味回到肉上——这是炭烤的灵魂。
    - name: 文火上料
      duration: 1–2 分钟
      body: 移到炉边余火处撒料收干。料在低温区吃进油里，不糊不苦。
  charcoal: 首选果木炭，耐烧、烟香干净；机制炭稳定但香气弱。烧到明火退去、炭面挂灰再上串。
  doneness: 边缘焦卷微翘、肥肉呈半透明琥珀色、整串油光发亮不滴生水。

localVariants:
  wuhan: 起锅前刷两遍蒜蓉甜辣酱，咸辣挂汁、油亮上色。重酱轻撒料，入口先辣后甜，蒜香收尾。
  anlu: 不刷酱，孜然粒加粗辣椒面干撒到位，靠油脂滴炭的烟熏香撑住整串。入口干香，越嚼越有炭火味。

pitfalls:
  - title: 切太厚
    body: 5 毫米以上的五花逼不出油，外焦里腻，嚼着像肥肉块而不是烤串。
  - title: 料撒太早
    body: 孜然辣椒面上炉就撒，还没等肉熟料先糊了，整串发苦。
  - title: 全程猛火
    body: 表面焦黑内里夹生，油也没逼出来。火候是三段式，不是一把梭。
