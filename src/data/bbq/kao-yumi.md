name: 烤玉米
category: 主食
summary: 整根糯玉米刷酱慢烤，颗粒饱满咬开爆汁
intro: 挑颗粒饱满的糯玉米整根上炉，中火慢慢转动烤透，刷两轮酱让每一颗玉米粒都挂上味——比起追求焦香，烤玉米更讲究烤透而不烤干，咬开还带着玉米本身的甜。

specs:
  - label: 处理方式
    value: 整根去皮留芯
  - label: 烤制时间
    value: 12–15 分钟
  - label: 每份用量
    value: 1 根

sourcing:
  body: 选**颗粒饱满、排列紧密**的糯玉米，甜玉米水分大烤出来容易发艮。掰开看颗粒是否鼓涨，太瘪的说明不新鲜或者本身品质一般。
  photoHint: 一两根去皮玉米的特写，露出颗粒饱满度
  checks:
    - title: 看颗粒
      body: 颗粒饱满鼓涨、排列紧密的更好。
    - title: 选品种
      body: 糯玉米比甜玉米更适合烤，口感软糯不发艮。
    - title: 看玉米须
      body: 须色泽新鲜（略带浅褐）说明采摘不久。

skewering:
  body: 整根玉米不切段不穿签，去掉外皮和大部分玉米须，留一截玉米芯当手柄，直接搁在烤网上转动着烤。
  diagram: none
  photoHint: 去皮后整根摆在烤网上的特写

marinating:
  body: 不预腌。整根玉米靠中途多次刷酱入味，预先腌制反而没办法均匀渗透进每一颗颗粒里。

seasoning:
  timeline:
    - when: 上炉初期
      what: 什么都不加
      body: 干烤让表面颗粒微微收紧，之后刷酱才挂得住。
    - when: 表面微黄后
      what: 刷一层薄油
      body: 补足油膜，方便干料和酱汁附着。
    - when: 快烤透时
      what: 刷酱（甜辣酱或蒜蓉酱）
      body: 转动着刷满整根，让每一面都挂上酱。
    - when: 起锅之前
      what: 辣椒面（可选）
      body: 喜辣的再补一轮辣椒面，不吃辣可以省略。

fire:
  body: 中火慢烤，靠不断转动让整根受热均匀，猛火只会外层烤焦、里面的颗粒还是生的。
  photoHint: 刷酱后颗粒饱满油亮的特写
  stages:
    - name: 中火烤透
      duration: 10–12 分钟
      body: 中火慢烤，勤转动，确保每一面颗粒都受热到位。
    - name: 刷酱收尾
      duration: 2–3 分钟
      body: 刷酱后再转动烤一会儿，让酱汁微微收干挂色。
  charcoal: 果木炭为佳，烤制时间长，稳定的炭火更省心。
  doneness: 颗粒表面微微起皱、颜色转深，牙签能轻松扎透颗粒，咬开还带汁水。

localVariants:
  wuhan: 常刷甜辣酱，口味偏甜辣。
  anlu: 更偏爱蒜蓉酱，咸香为主，甜味很淡。

pitfalls:
  - title: 用甜玉米代替糯玉米
    body: 甜玉米水分大，烤久了容易发艮变硬，口感不如糯玉米软糯。
  - title: 不转动
    body: 只烤一面，另一面还是生的，整根受热不均。
  - title: 刷酱太早
    body: 表皮还没收紧就刷酱，酱汁大量滴落到炭火里，容易烧糊起烟。
