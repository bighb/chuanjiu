sourcing:
  body: 选**牛里脊或上脑**等嫩部位，纹理细腻少筋膜。要冷鲜牛肉，色泽鲜红有光泽，摸起来紧实不出水。冻肉解冻后纤维松散，锁不住汁水，不适合这种快烤吃法。
  photoHint: 一块牛肉的横切面，露出纹理与色泽
  checks:
    - title: 看颜色
      body: 鲜红有光泽，不要发暗发紫。
    - title: 看纹理
      body: 纹理细腻，筋膜少的部位更嫩。
    - title: 摸质感
      body: 按压紧实回弹，不出血水。

skewering:
  body: 逆纹切成 **2–3 毫米薄片**，逆纹切断肌肉纤维，烤出来才不发柴。竹签波浪式穿入，一串 4–5 片，片间留缝方便快速受热。
  diagram: wave
  diagramNote: 薄片呈 S 形过签，受热面积最大，几十秒就能烤透。
  photoHint: 穿好的一串平放特写，能看清切面纹理

marinating:
  body: 不预腌，图的就是现切现烤的新鲜劲——预先腌制反而掩盖了牛肉本身的味道，也失了「生烤」这个名字的本意。

seasoning:
  timeline:
    - when: 上炉初期
      what: 什么都不加
      body: 猛火快速锁住肉汁，此时撒料没有意义，反而容易糊。
    - when: 表面变色后
      what: 盐 + 黑胡椒
      body: 简单调味，突出牛肉本身的鲜味，不用复杂料汁盖过去。
    - when: 起锅之前
      what: 孜然粉 + 少许辣椒面
      body: 最后一轮撒料增香，动作要快，避免久烤发柴。

fire:
  body: 猛火快烤，全程时间极短，图的就是外层微焦、内里还带一点粉嫩的口感。
  photoHint: 断面粉红、边缘微焦的特写
  stages:
    - name: 猛火锁汁
      duration: 1–2 分钟
      body: 高温快速让两面变色定型，锁住内部肉汁。
    - name: 撒料收尾
      duration: 1 分钟
      body: 撒料翻两下即可出炉，久烤会让薄片牛肉发柴变硬。
  charcoal: 果木炭为佳，猛火短时间烤制，炭火干净不呛烟更重要。
  doneness: 表面微焦上色、断面还带一点粉嫩，不是完全灰白——太熟的牛肉片会发硬发柴。

pitfalls:
  - title: 烤过头
    body: 薄片牛肉经不起久烤，超过 3 分钟基本就发柴发硬，鲜嫩感全无。
  - title: 切太厚
    body: 厚片不容易快速烤透，为了熟透只能延长时间，结果外层先柴了。
  - title: 顺纹切
    body: 没有逆纹切断纤维，嚼起来发韧，牙口不好的人会觉得费劲。
